An interactive campus skill-exchange marketplace prototype where students can discover, offer, and exchange skills using a virtual currency called LOOT.

💡 About the Project

The Treasure Hunt is designed as a student-focused platform that connects students who need help with students who have useful skills.

Users can explore different services, view a student's profile, hire a "Hunter," and simulate transactions using LOOT.

✨ Features
🗺️ Skill Marketplace – Browse different student skills and services
🔍 Skill Search – Search for specific skills
👤 Hunter Profiles – View the provider's skill and description
💰 LOOT Wallet – Simulated virtual balance
🔐 Escrow Simulation – Demonstrates how payments could be held during a transaction
📊 Platform Fee – Demonstrates a 3% platform commission
🎫 College Verification – Prototype concept for college-domain verification
📱 Responsive Design – Works across different screen sizes

🚀 How to Run
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
Explore the Treasure Hunt prototype.

No server or database is required for this prototype.

⚠️ Current Status

This project is a front-end prototype.

The payment system, user authentication, database, and real Razorpay integration are currently simulated and are not connected to a live backend.
